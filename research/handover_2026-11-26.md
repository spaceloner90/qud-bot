## 2. What we learned does NOT work (harness latency)

- **Windows cold-shell floor:** A harness that spawns a fresh sandboxed PowerShell session per command has
  a ~5-6 s fixed startup floor even for `python --version` or `say.py`, and parallel shell calls serialize
  (~13-14 s for `send.py` + `say.py` in the same turn).
- **File-piped warm daemon (`tools/exec_daemon.py`) did not beat the floor:** Although `exec_daemon.py`
  executed `tools/send.py` in ~0.10 s internally, piping via `write_file(live/exec_in.txt)` and reading
  `live/exec_last.txt` forces **two LLM turns** per game turn (send turn + read turn), adding an extra
  ~4-6 s model round-trip that cancels the ~5 s shell savings (~11 s total either way).
- **Takeaway:** Fast turn-by-turn hand play requires a harness with a persistent warm shell (blocking
  command execution with <1 s overhead, returning stdout in the same tool call). `tools/exec_daemon.py` is
  left in the repo as a documented experiment (not recommended in `AGENTS.md`).

These apply to **any** agent/model (Claude, Gemini, etc.) and were deferred by the owner until vetted:

1. **Single-call hand-over digest (`tools/brief.py`):**
   - Today, every hand-over requires reading raw `live/state.json` (~10 KB single line dominated by the
     80x25 screen buffer and `fg` color matrix), reading `live/narration.log`, and checking `world.py` /
     `known.py`.
   - A compact `python tools/brief.py` printing one structured block — vitals/hunger/effects/position,
     cropped local map around `@`, visible hostiles & objects with their `game_knowledge.json` verdicts,
     pending liquids/features, equipped + pack summary, active quests, last messages, and last narration
     lines — would cut tokens/latency and improve checklist compliance on every hand-over.
2. **Batch narration with action commands (`--say` / `--think` flags):**
   - `tools/send.py` already supports `-m` for `SAY`, but `say.py` (voice) and `think.py` (panel thought)
     require separate CLI calls.
   - Adding optional `--say "..."` and `--think "..."` flags to `send.py`, `walk.py`, and `next_zone.py`
     cuts tool calls per turn and keeps narration synchronized with actions.
3. **Compact 1-page CLI index for core `tools/` scripts:**
   - There are 30+ scripts in `tools/`. `AGENTS.md` rightly forbids calling tools from memory, which costs
     several docstring-read turns on a fresh context.
   - A concise `tools/INDEX.md` (or short table in `AGENTS.md`) covering the ~10 core live-play tools
     (`send`, `walk`, `menu`, `wait`, `next_zone`, `watch_handover`, `world`, `known`, `say`, `think`) with
     exact flags and exit codes saves startup turns safely.
4. **Pinned "active gotchas" header for growing append-only notes:**
   - `research/lessons.md` and `research/game_facts.md` are append-only (~300 lines combined today). As
     more runs accumulate, keeping a short pinned top summary (or letting `AGENTS.md` stay the distilled
     layer) keeps fresh-context startup fast without losing history.
